# Engineering English — IoT / IP Camera

Randomized English vocabulary practice for Mechanical Engineering and IoT/IPCam interviews.

## Included
- 365 unique vocabulary / interview expressions
- 161 new IoT/IPCam-focused entries
- 1 exact duplicate removed from the previous bank
- Listening and slow pronunciation
- Microphone speech recognition
- English fill-in-the-blank
- Automatic correct/incorrect checking
- English / Chinese comparison
- Randomized order for every new round

## GitHub Pages
Upload `index.html` to the repository root, then:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Use the HTTPS GitHub Pages URL and allow microphone access for speech recognition.
